# Cuadrado Mobile Hub · Android App Base
Aplicación móvil Android para el seguimiento en tiempo real del Círculo Soberano SENI-IA y visualización de reportes notariales con 20 temas visuales.

## Objetivo
- Visualización de telemetría y reportes desde el servidor local: `http://192.168.1.136:5678/reportes_circulo/index.html`.
- Soporte táctil optimizado para Realme P3 (Android 14/15, 12 GB RAM, 120Hz).
- Compatible con Google AI Studio App Builder.
